Universal Trinkets README
=========================

This file was generated by the Universal Trinkets mod.
Trinket behaviors can be customized via configuration files and commands.

IMPORTANT: When placing commands for trinkets in the config file, be sure to include a backslash before any quotation marks.
The code will automatically remove these escape characters when executing the commands.

**For giving players items, it is recommended to use the summon command:
summon item ~ ~ ~ {Item:{id:"<Item name>",count:<amount>}}**
Using the standard give command may lead to unexpected behavior.

		[Config Usage]

[Animation]
  Enables or disables the totem-like animation when the item is used.
  true = enabled, false = disabled

[Remove on use]
  Makes trinkets one-time use by removing them after use.
  Useful if other mods prevent items from fully breaking.
  true = enabled, false = disabled

[Damage on use]
  Enables or disables durability damage to trinkets.
  Disable this and [Remove on use] to make trinkets permanent.
  true = enabled, false = disabled

[Damage amount per use]
  Sets the durability damage each use inflicts.
  For example, setting this to 1 allows approximately 1000 uses,
  while setting it to 100 allows about 10 uses.

[Return to world spawn]
  Teleports the player to the world spawn point.
  This affects only command 2 and is useful for timed teleportation to other dimensions.
  true = enabled, false = disabled

[Cmd 1]
  Sets the first command executed by the trinket.

[Time to trigger cmd 2]
  Sets the delay in ticks before command 2 runs.
  Once started, the timer continues even if the player changes dimensions or dies.
  The timer only stops if the player logs out.
  Setting this to 0 disables the second command.

[Cmd 2]
  Sets the second command executed by the trinket.

[Tri-command]
  A group of commands including [Tcmd1], [Tcmd2], and [Tcmd3] that run simultaneously,
  triggered 20 ticks after [Cmd 1].
  The entire Tri-command group is enabled or disabled by [Tcmd enable].

[Tcmd enable]
  true = enable, false = disable

[Cooldown Timer]
  Sets the time before the item can be used again. Set to 0 to disable.

Always create a backup of your configuration file before making changes.
[Random Chance]
  Allows trinket effects to trigger based on chance.
  true = enabled, false = disabled

[Chance]
  Sets the trigger chance of trinket.
  0 = 0% chance, 100 = 100% chance

Always create a backup of your configuration file before making changes.
